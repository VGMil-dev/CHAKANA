# 🚀 CHAKANA — Plan de 48 Horas para Hackathon (Solana)

## 🎯 Objetivo del Demo
En 2 minutos debes poder:
1. Conectar wallet
2. Escribir una reseña
3. Guardar un hash en blockchain
4. Mostrar verificación
5. Mostrar reputación simple

---

# ⏱️ DÍA 1 (0–24h) → “Que funcione”

## 🕐 Hora 0–2 → Setup
- Crear repo
- Next.js app
- Instalar dependencias Solana
- Conectar wallet

✅ Meta: botón “Conectar wallet”

---

## 🕐 Hora 2–6 → Conexión a red
- Conectar a devnet
- Mostrar dirección y balance

---

## 🕐 Hora 6–12 → Núcleo (CRÍTICO)
- Usuario escribe reseña
- Generar hash (SHA256)
- Enviar a blockchain

---

## 🕐 Hora 12–16 → Confirmación
- Mostrar hash
- Link a explorer
- Estado verificado

---

## 🕐 Hora 16–20 → UI básica
- Textarea
- Botón publicar
- Lista de reseñas

---

## 🕐 Hora 20–24 → Reputación
- Contador de reseñas
- Nivel básico

---

# ⏱️ DÍA 2 (24–48h) → “Que gane”

## 🕐 Hora 24–28 → Mejorar narrativa
- Cambiar textos técnicos a lenguaje usuario

---

## 🕐 Hora 28–32 → Aurios simple
- +10 Aurios por reseña
- Mostrar recompensa

---

## 🕐 Hora 32–36 → Tambu demo
- Crear negocio ficticio
- Asociar reseñas

---

## 🕐 Hora 36–40 → Demo fluido
- Flujo completo en <90s

---

## 🕐 Hora 40–44 → Pitch

---

## 🕐 Hora 44–48 → Testing
- Probar todo
