## Resumen
CHAKANA es una plataforma ancestral-moderna para economía circular local. Combina experiencia móvil, verificación en blockchain e incentivos programables para que el impacto comunitario sea confiable, recompensado y escalable.

## Por Qué Importa
- **Confianza desde el origen:** Las acciones comunitarias se pueden verificar y auditar.
- **Incentivos reales:** El modelo de token Aurio conecta valor social con valor económico.
- **Comercio inclusivo:** Los negocios locales acceden a flujos de valor digitales.
- **Narrativa + datos:** Historias humanas e impacto medible conviven en una sola experiencia.

## Golden Path de Hackathon (Demo para Jurado)
1. Una persona conecta su wallet.
2. Se envía una reseña/acción.
3. Un hash verificable se ancla en blockchain.
4. Se activa la lógica de recompensa (flujo Aurio).
5. El valor para comercios/comunidad se visualiza en la app.

## Pilares del Producto
- **Reseñas verificadas y reputación**
- **Recompensas Aurio y lógica de descuentos**
- **Herramientas para comercios (Tambús, productos, órdenes)**
- **Propinas cross-chain e interoperabilidad de pagos**
- **Reporte de voz asistido por IA para narrativa de impacto**

## Ecosistema y Tecnologías
- **Mobile:** Expo + React Native
- **Estado y lógica de app:** Zustand
- **Blockchain:** Solana (Devnet)
- **Backend:** Supabase (Auth, Postgres, RLS, Edge Functions)
- **Pagos:** Stripe
- **Cross-chain:** LI.FI
- **IA de voz:** ElevenLabs (solo backend)

## Notas Importantes
> **Nota de seguridad:** Las llaves y secretos no se versionan; las operaciones sensibles viven en backend.

> **Nota de MVP:** Este repositorio prioriza un demo funcional de 48h sobre complejidad no esencial.

> **Nota de alcance:** Esta documentación está orientada a jurado; se excluyen guías de instalación/desarrollo de forma intencional.
