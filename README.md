## ✨ Overview
CHAKANA is an ancestral-modern platform for local circular economy. It combines mobile UX, blockchain verification, and programmable incentives so community impact can be trusted, rewarded, and scaled.

## 🎯 Why This Matters
- **Trust at source:** Community actions can be verified and audited.
- **Real incentives:** The Aurio token model connects social value with economic value.
- **Inclusive commerce:** Local businesses gain tools to participate in digital value flows.
- **Narrative + data:** Human stories and measurable impact live in one experience.

## 🧭 Hackathon Golden Path (Jury Demo)
1. A user connects a wallet.
2. A review/action is submitted.
3. A verifiable hash is anchored on blockchain.
4. Reward logic is triggered (Aurio flow).
5. Merchant/community value is visible in-app.

## 🧱 Product Pillars
- **Verified Reviews & Reputation**
- **Aurio Rewards & Discount Logic**
- **Merchant Tools (Tambús, products, orders)**
- **Cross-chain tipping and payment interoperability**
- **AI-assisted voice reporting for impact storytelling**

## 🛠️ Ecosystem & Technologies
- **Mobile:** Expo + React Native
- **State & App Logic:** Zustand
- **Blockchain:** Solana (Devnet)
- **Backend:** Supabase (Auth, Postgres, RLS, Edge Functions)
- **Payments:** Stripe
- **Cross-chain:** LI.FI
- **Voice AI:** ElevenLabs (backend-only)
